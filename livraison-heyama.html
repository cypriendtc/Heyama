Stack technique

API NestJS, Mongoose, MinIO S3, Swagger
Web Next.js 14, shadcn/ui, Tailwind
Mobile React Native, Expo SDK 57
Infra Docker, PM2, Apache
Base de donnees MongoDB
Temps reel Socket.IO

Fonctionnalites livrees

  • CRUD complet des objets Creation avec upload d'image, consultation, suppression. API REST + interface web et mobile.
  • Upload et stockage d'images via MinIO (S3) Les images sont stockees sur un bucket S3-compatible et servies via le proxy Apache.
  • Optimisation des images Compression automatique en WebP (max 1200px, qualite 80) et generation de thumbnails (400px) via sharp. Reduction d'environ 90% du poids.
  • Temps reel via WebSocket Les nouveaux objets et suppressions apparaissent instantanement sur tous les clients connectes.
  • Recherche instantanee Filtrage en temps reel pendant la saisie (debounce 300ms). Recherche par titre et description.
  • Pagination Web : navigation par pages. Mobile : scroll infini avec "Charger plus".
  • Multilingue FR / EN Switcher de langue dans le header, web et mobile, avec persistance du choix.
  • Design responsive Interface adaptee mobile, tablette et desktop avec la charte graphique Heyama (violet).
  • Documentation API interactive Swagger UI accessible a /api/docs. Permet de tester tous les endpoints depuis le navigateur.
  • Application mobile Android (APK) Build via EAS Build. Distribution interne pour tests.
